# Kẽm Nhung — design system

Mở thư mục này trong VS Code, rồi chép thư mục `design-system/` và file `CLAUDE.md` vào gốc dự án web của bạn (nếu dự án đã có `CLAUDE.md`, dán nội dung vào cuối file).

- `design-system/pop/` — bản rực rỡ (đang dùng mặc định)
- `design-system/pastel/` — bản pastel
- Mỗi bản: `tokens.css`, `tokens.json`, `components.css`, `README.md` (brand book), `components/*.md` (hướng dẫn), `examples/*.html` (mở `examples/index.html` để xem)

Ví dụ yêu cầu cho Claude Code:
- "Dựng trang chủ theo design system: banner video, Set DIY bán chạy, thành phẩm cộng đồng"
- "Chuyển các component trong design-system/pop sang React + TypeScript"
- "Làm trang bài hướng dẫn với video, MaterialList và StemCalculator"
